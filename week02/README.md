# 2주차

## 오늘 배운 내용

1. 가상화 (서버, 베어메탈/하이퍼바이저/컨테이너 비교)
   - 가상화 : **물리적**인 컴퓨팅 환경 내에서 여러 개의 **논리적**인 컴퓨팅 환경을 만들 수 있는 기술
     - **베어메탈** : PC 1개 + OS 1개 + 소프트웨어 n개
     - **하이퍼바이저** : 호스트 OS 1개 + VM(가상머신) n개   
       호스트 OS 리소스 -> 게스트 OS 실행
       각 가상머신은 자신의 게스트 OS와 커널을 가짐
     - **컨테이너** : 호스트 OS + 컨테이너   
       호스트 OS의 커널 기능으로 격리된 공간   
       모든 컨테이너가 호스트 OS의 커널을 공유 (호스트 OS와 다른 종류의 OS 실행 불가)
           
2. WSL2 + Ubuntu
   - WSL : 가상머신보다 적은 리소스, 파일 탐색기 접근 가능, bash 명령어 사용 가능
   - Ubuntu 설치
  <pre>
    <code>
      wsl —install -d Ubuntu
      wsl —install -d Ubuntu-24.04  // 특정 버전 설치
    </code>
  </pre>
  <pre>
    <code>
      wsl --set-default Ubuntu-24.04
      wsl --set-default-version 2  // 앞으로 설치할 Ubuntu 기본 값을 2로
      wsl --set-version Ubuntu-24.04 2  // 이미 설치된 특정 Ubuntu 변경
    </code>
  </pre>

3. 기본 리눅스 명령어
   - pwd
   - ls
     - -l : 권한, 링크, 소유자, 그룹, 크기, 수정시간, 파일명 출력
     - -a : 숨김 파일까지 출력
   - chmod <권한> <파일 이름>   
     - +x(o, g, u 모두에게 실행 권한 부여), u+r(소유자에게 읽기 권한 부여)   
     - 755(소유자에게 rwx, 그룹에게 rx, 기타 사용자에게 rx 권한 부여)   
       (r=4, w=2, x=1)
   - cat   
     - cat > : 앞 파일 내용들을 합쳐서 파일에 기록   
     - cat >> : 앞 파일 내용들을 합쳐서 파일에 추가
   - history   
     - !103 : 히스토리 중 103번째 명령어 실행   
     - !! : 바로 직전 명령 다시 실행
